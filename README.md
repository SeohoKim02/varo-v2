# Varo V2

편의점 냉장·냉동 상품의 **악성(과잉/임박) 재고를 어디로 얼마나 옮길지** 판단하도록 돕는
Streamlit 기반 재고 의사결정 프로그램입니다. 재고 담당자가 엑셀 데이터를 넣으면, 실행 가능한
이동 후보를 만들고 VHS 점수로 우선순위를 매겨 **추천 이동(출발 점포 → 도착 점포, 수량, 경로)**
을 제시합니다.

> 이 문서는 실제 사용자를 위한 시작 안내입니다. 알고리즘 원리는 [`docs/ALGORITHM.md`](docs/ALGORITHM.md),
> 데이터 형식은 [`docs/DATA_SCHEMA.md`](docs/DATA_SCHEMA.md), 검증 방식은
> [`docs/VALIDATION.md`](docs/VALIDATION.md), 단계별 사용법은 [`docs/USER_GUIDE.md`](docs/USER_GUIDE.md)
> 를 참고하세요.

## 해결하는 문제

- 어느 점포에 재고가 과잉이고 어느 점포에 부족한지 한눈에 보기 어렵다.
- 폐기 위험이 큰 재고를 이동으로 살릴 수 있는지, 이동 비용 대비 효과가 있는지 판단이 필요하다.
- "그래서 무엇을 옮겨야 하는가"에 대한 실행 가능한 추천이 필요하다.

Varo V2는 이 판단을 **VHS(Varo Hybrid Score) 다기준 점수**로 종합해 우선순위를 제시합니다.
Greedy(단순 기준선)·Pareto(비지배 검증)·DQN(선택형 참고)은 비교·검증 보조 수단이며,
**최종 추천과 순위는 항상 VHS가 담당**합니다.

## 설치

- Python 3.11 권장
- 의존성: `streamlit`, `pandas`, `altair`, `openpyxl` (엑셀), 그리고 **선택 사항**으로 `torch`(DQN 학습 시에만)

```bash
python -m pip install streamlit pandas altair openpyxl
# DQN 학습을 직접 실행할 때만 추가 (없어도 앱은 정상 동작):
python -m pip install torch
```

## 실행

```bash
python -m streamlit run app_v2.py --server.headless true --server.port 8501
```

브라우저에서 `http://localhost:8501` 을 엽니다.

## 기본 사용 순서

1. **데이터 관리** 페이지에서 기본 샘플을 불러오거나, 상단 데이터 바에서 엑셀 파일을 업로드합니다.
2. 업로드 파일은 먼저 **검사**만 됩니다. 검사 결과(오류/경고/사용 가능)를 확인하고 **"이 데이터 사용"**
   (또는 "문제 행을 제외하고 사용")을 눌러야 적용됩니다. 자세한 단계는 아래 "파일 선택 → 검사 → 적용" 참고.
3. **추천 실행** 페이지에서 **"추천 실행"**을 눌러 적용된 데이터로 계산합니다.
4. **홈(운영 현황)** 에서 핵심 KPI와 추천 신뢰도, 이동 시뮬레이션을 확인합니다.
5. **경로 상세** 페이지에서 선택한 추천 한 건의 이동 조건·대안·이동 전후 재고를 봅니다.
6. 필요할 때만 **분석 및 검증** 페이지에서 안정성·비교·DQN 등을 확인합니다. 이 페이지는 홈과 같은 상태를
   사용해, 추천 결과가 있을 때만 알고리즘 탭을 열고 후보가 0건이면 원인과 후보 판단 요약을 보여줍니다.

## 홈 화면 상태

홈(운영 현황)은 현재 상태에 따라 **하나의 상태와 다음 행동 하나**만 보여줍니다. 추천 결과가 있을 때만
결과 KPI(추천 후보·권장 이동 수량·예상 순효과·추천 신뢰도·데이터 상태)와 최우선 추천 카드가 나타납니다.

| 상태 | 홈 표시 | 다음 행동 |
| --- | --- | --- |
| 데이터 없음 | "데이터를 준비하세요" | 데이터 불러오기 → 데이터 관리 |
| 검사한 데이터 있음(미적용) | "검사한 데이터를 적용하세요" | 데이터 적용 → 데이터 관리 |
| 사용 불가 업로드(적용 데이터 없음) | "데이터를 수정해야 합니다" (핵심 오류) | 문제 확인 → 데이터 관리 |
| 데이터 적용 완료·추천 실행 전 | "추천 실행 준비가 완료되었습니다" | 추천 실행 → 추천 실행 |
| 추천할 이동 없음 | "추천할 이동이 없습니다" (제외 원인) | 제외 이유 확인 → 추천 실행 |
| 추천 결과 있음 | 결과 KPI + 최우선 추천 카드 | 추천 상세 보기 → 경로 상세 |

실행 전이나 계산 실패 상태에서 결과 수치를 0으로 채우지 않습니다. **이미 적용된 정상 데이터가 있으면**,
새로 올린 파일이 오류·정상 어느 상태든 홈은 현재 결과를 유지하고 "검사 완료된 새 데이터가 있습니다"라는
짧은 안내만 표시합니다(적용은 데이터 관리에서 직접). 새 데이터를 실제로 **적용**하면 이전 추천·KPI는
초기화되며, 추천 실행 버튼을 누른 뒤 새 결과가 만들어집니다.

## 데이터 업로드 방법

- 상단 데이터 바의 업로드 위젯에 파일을 올립니다. 지원 형식: **`.xlsx` · `.xls` · `.csv`**.
  지원하지 않는 형식·빈 파일·손상된 파일은 즉시 짧은 안내로 차단됩니다(오류 로그만 내부 보관).
- **CSV는 표 하나만 담을 수 있어** 분석에 필요한 여러 시트(점포·상품·재고·경로)를 만들 수 없으므로,
  여러 시트가 있는 Excel 워크북을 권장합니다(CSV는 안전하게 읽되 Excel로 안내).
- 컬럼명은 한글/영문 별칭으로 표준 컬럼에 자동 매핑됩니다(`services/column_aliases.py`).
- **추천 결과 시트가 없으면** 재고·경로 데이터로 후보를 자동 생성합니다(rule-based).
- 필수 컬럼·시트가 부족하면 추천 계산을 **보류**하고, 데이터 관리의 "데이터 점검"에서 어느 행·컬럼을
  고쳐야 하는지 보여줍니다(문제 목록 CSV 내려받기 가능).
- 필요한 컬럼과 형식은 [`docs/DATA_SCHEMA.md`](docs/DATA_SCHEMA.md)에 정리되어 있습니다.

## 파일 선택 → 검사 → 적용 → 추천 실행 (2단계 적용)

파일을 올렸다는 이유만으로 현재 데이터가 바뀌지 않습니다. **검사와 적용은 별도 단계**입니다.

1. **파일 선택** — 상단 데이터 바에서 `.xlsx`/`.xls`/`.csv`를 올립니다. 파일을 읽어 검사만 하고,
   현재 사용 중인 데이터와 추천 결과는 그대로 둡니다("검사 중인 데이터"로 표시).
2. **검사 결과 확인** — 데이터 관리에서 파일명·시트·전체/분석 사용/오류/경고/제외 행, 주요 문제,
   미리보기, 적용 가능 여부를 확인합니다.
3. **데이터 적용** — 사용자가 직접 누릅니다. 정상은 **"이 데이터 사용"**, 유지 경고만 있으면
   **"확인 후 이 데이터 사용"**, 실제 제외 행이 있으면 **"문제 행을 제외하고 사용"**입니다.
   구조 오류이거나 제외 후 재검증에 실패하면 적용 버튼이 없습니다. 적용해야 비로소 현재 데이터가
   교체되고 이전 추천·후보·경로·시뮬레이션 결과가 초기화됩니다(같은 데이터면 불필요한 초기화 없음).
4. **추천 실행** — 적용이 끝나면 "추천 실행"으로 이동해 계산 버튼을 누릅니다. 업로드 적용만으로
   VHS·Greedy·Pareto 분석이나 DQN 학습이 자동 실행되지 않습니다.

안전하게 분리할 수 있는 개별 행만 원본 행 번호로 제외합니다. 필수 시트·컬럼 누락, 별칭 충돌,
핵심 테이블 소실처럼 파일 구조를 신뢰할 수 없는 오류는 자동으로 무시하지 않으며 파일 전체를 차단합니다.
제외 전에는 적용 예정 행과 제외 이유를 확인하고 문제 목록 CSV를 내려받을 수 있습니다.

> 기본 샘플(데이터 관리의 "선택한 샘플 적용")은 버튼 클릭이 곧 적용이므로 한 번에 적용됩니다.

## 데이터 관리 화면

데이터 관리 페이지는 홈과 **같은 상태 문구**를 쓰며, 현재 앱에 적용된 데이터("현재 사용 중 데이터")와
아직 적용되지 않은 업로드("검사 중인 데이터")를 분명히 구분합니다.

- 새 파일이 오류·정상·경고 어느 상태든, **적용 버튼을 누르기 전까지** 기존 정상 데이터와 추천은 유지됩니다.
- 새 파일이 사용 불가라도 홈·추천 실행은 현재 적용 데이터로 계속 동작합니다(전체 앱이 멈추지 않음).
  홈에는 "검사 완료된 새 데이터가 있습니다"라는 짧은 안내만 표시됩니다.
- 사용 불가 데이터에는 적용 버튼이 없고, 문제 행·수정 방법과 "문제 목록 CSV 내려받기"를 제공합니다.
- 적용에 실패하면 기존 사용 데이터와 검사 결과를 그대로 보존하고 짧은 안내만 보여줍니다.
- "검사 중인 데이터 취소"는 검사 결과만 지우고 현재 데이터는 유지합니다.
- "현재 데이터 초기화"는 앱에 적용된 데이터와 결과만 비우며, 사용자의 원본 파일은 삭제하지 않습니다.

## 추천 결과 읽는 법

각 추천은 다음을 보여줍니다.

- **출발 → 도착 점포, 상품, 권장 이동 수량, 경로 유형(DIRECT / VIA_DC), 예상 순효과**
  (예상 순효과 = 예상 절감액 − 이동 비용. 절감액과 이동 비용 각각은 후보 상세에서 확인)
- **실행 상태**: `추천 가능` / `데이터 확인 필요` / `이동 불가`(제외됨)
- **추천 안정성**: `안정` / `검토 필요` / `변동 가능성 큼` (판단 기준이 바뀌어도 순위가 유지되는지)
- **추천 신뢰도**: `높음` / `보통` / `낮음` / `계산 불가` — 성공 확률이 아니라 상대적 신뢰 표시
- **짧은 추천 이유**(최대 3개): 과잉/부족·폐기 위험·비용 대비 효과·경로 조건 등 실제 계산 근거
- **이동 수량 근거**: 무엇이 수량을 제한했는지 한 줄로(예: "도착 점포 부족량을 기준으로 12개 이동을 권장합니다.")
- **원본 데이터 확인**(접힘): 판단에 쓰인 원본 파일·시트·행·입력값. 데이터 관리 문제 목록과 같은 행을 가리킵니다.
- **추천에서 제외된 후보**(접힘): 사라지지 않고 상태·핵심 이유·원본 위치와 함께 확인하고, 검토 CSV로 내려받을 수 있습니다.

값이 계산되지 않으면 `-`, `데이터 없음`, `확인 필요`, `계산 불가`로 **정직하게 표시**합니다.
없는 값을 0이나 정상으로 위장하지 않습니다.

## DQN은 선택형 보조 기능입니다

- DQN은 **자동 실행되지 않습니다.** 분석 및 검증 → DQN 학습 탭에서 버튼을 눌렀을 때만 학습/추론합니다.
- DQN 결과는 **정상 상태 + 현재 데이터 일치 + 안정성 통과**일 때만 낮은 비중으로 참고 반영되며,
  최종 추천과 순위는 언제나 VHS가 결정합니다.
- `torch`가 없으면 "실행 환경 필요"로만 표시하고 가짜 결과를 만들지 않습니다.

## 현재 지원 범위

- 5개 페이지: 홈(운영 현황) · 추천 실행 · 경로 상세 · 분석 및 검증 · 데이터 관리
- 엑셀 업로드/샘플 적용, 실행 가능성 필터, VHS 추천·순위, Greedy·Pareto 비교 검증, 선택형 DQN
- 네트워크/이동 시뮬레이션(DIRECT 실선 · VIA_DC 점선, DC01/DC02 구분)

## 실제 사용 시 주의사항

- 샘플 데이터는 시연·검증용이며 실제 운영 데이터가 아닙니다.
- 일부 선택 컬럼이 없으면 해당 VHS 구성요소에 중립값(50)이 적용되어 분석이 제한될 수 있습니다.
- DQN 학습 샘플 팩(`Varo_DQN_training_samples_10pack`)은 이 저장소에 포함되지 않는 외부 데이터입니다.
- 카카오 지도·PDF·발표용 요약은 이 프로그램의 범위가 아닙니다.
