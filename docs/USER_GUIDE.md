# Varo V2 사용 가이드

재고 담당자가 실제 데이터로 이동 추천을 얻기까지의 단계별 안내입니다. 설치·실행은
[`../README.md`](../README.md)를 먼저 참고하세요.

## 1. 데이터 준비

- 엑셀(`.xlsx`/`.xls`)에 `stores`, `products`, `inventory`, `routes` 시트를 준비합니다(사전 추천 시트는 선택).
- **파일 형식**: `.xlsx`·`.xls`·`.csv`를 올릴 수 있습니다. 단 CSV는 표 하나만 담을 수 있어 4개 시트를
  만들 수 없으므로, 여러 시트가 있는 Excel 워크북을 권장합니다(CSV는 안전하게 읽되 Excel로 안내).
- 시트는 **이름으로** 인식합니다(첫 시트를 임의로 쓰지 않음). 필수 시트 이름이 없으면 무엇이 없는지 안내합니다.
- 컬럼명은 한글/영문 어느 쪽이든 자동 매핑되지만, 필수 컬럼은 반드시 있어야 합니다
  ([`DATA_SCHEMA.md`](DATA_SCHEMA.md)).
- 점포는 `node_type=STORE`, 물류센터는 `node_type=DC`로 구분합니다. DC가 여러 개면 각각 DC 행으로 둡니다.

## 1-1. 검증 결과 읽는 방법

데이터 관리 페이지에서 확인합니다.

- **데이터 검증**: 통과 / 주의 / 오류. 오류면 추천이 적용되지 않습니다.
- **데이터 점검**: "전체 N행 중 M행을 분석에 사용합니다"와 오류 행·경고 행·사용 가능한 행·제외될 행 수,
  그리고 "가장 먼저 확인할 문제" 상위 5개를 보여줍니다. 전체 문제는 접힌 표, 수정용 파일은
  "문제 목록 CSV 내려받기"로 받습니다.
- **행/컬럼/입력값 찾기**: 문제 표의 `행`은 엑셀을 열었을 때 그대로 보이는 **파일 기준 행 번호**입니다
  (헤더가 1행이라 첫 데이터는 2행). `컬럼`은 파일에 쓴 **원본 컬럼명**(예: "현재고")이고, `입력값`은
  실제로 입력한 원본 값입니다. 여러 시트가 있으면 `시트`로 어느 시트인지 확인합니다.
- 예: `2행 / 현재고 / "십오" / 오류 / 숫자로 읽을 수 없습니다 / 해당 값을 숫자로 수정하세요`.
- 숫자 변환 실패 값은 원본 그대로 보이고(예: "십오") 상세/CSV의 "정규화 값"에 "변환 실패"로 표시됩니다.
  빈 값은 "빈 값"으로 표시합니다.

## 1-2. 사용 불가 데이터 수정 방법

1. 데이터 점검의 문제 목록(또는 CSV)에서 시트·행·원본 컬럼·입력값·수정 방법을 확인합니다.
   CSV에는 파일명·시트명·원본 행 번호·원본 컬럼명·입력값(전체)·정규화 값·수정 방법·관련 행이 들어 있습니다
   (Excel에서 한글이 깨지지 않도록 UTF-8 BOM).
2. 원본 엑셀에서 해당 셀을 고칩니다(예: 문자열 재고 → 숫자, 빈 상품 ID 입력, 출발지=도착지 수정).
3. 파일을 다시 업로드합니다. 오류가 사라지면 "이 데이터 사용" 버튼이 나타나며, 그 버튼을 눌러야 적용됩니다
   (수정 전까지는 기존에 쓰던 데이터가 그대로 유지됩니다).

- **값이 충돌하는 중복**(같은 점포·상품인데 재고가 다름)은 임의로 합치지 않습니다. 문제 메시지의
  "12행·27행" 같은 관련 행을 보고 원본에서 올바른 값 하나로 정리하세요.
- **컬럼 이름 충돌**("'현재고'와 '재고' 컬럼이 같은 항목으로 인식됐습니다")은 한 컬럼만 남기거나
  서로 다른 의미면 컬럼명을 구분하세요.
- **식별자 앞자리 0**(예: 001 → 1)은 엑셀이 저장할 때 이미 바뀐 것이라 앱이 되살릴 수 없습니다.
  원본에서 해당 열을 텍스트 서식으로 바꿔 다시 저장하세요.

## 1-3. 파일 선택 → 검사 → 적용 (2단계)

**파일을 올렸다는 이유만으로 현재 데이터가 바뀌지 않습니다.** 검사와 적용은 별도 단계입니다.

1. **파일 선택**: `.xlsx`·`.xls`·`.csv`를 상단 데이터 바에서 올립니다. 파일을 읽어 **검사만** 하고,
   현재 사용 중인 데이터와 추천 결과는 그대로 둡니다. 검사가 끝나면 "데이터 관리에서 적용하세요" 안내가 뜹니다.
2. **검사 결과 확인**(데이터 관리 → "검사 중인 데이터"): 파일명·시트, 전체/분석 사용/오류/경고/제외 행,
   주요 문제, 미리보기, 적용 가능 여부를 봅니다. 검사 상태는 네 가지입니다.
   - **사용 가능** — 오류 없음 → **"이 데이터 사용"** 버튼.
   - **확인 필요** — 경고가 있지만 분석 가능 → **"문제 행을 제외하고 사용"** 버튼(제외/사용 행 수 표시).
   - **사용 불가** — 필수 오류가 있어 적용 버튼이 없습니다. 문제를 고쳐 다시 올립니다.
   - **현재 데이터와 동일** — 지금 쓰는 데이터와 내용이 같아 다시 적용할 필요가 없습니다.
3. **데이터 적용**: 위 버튼을 **직접 눌러야** 현재 데이터가 교체됩니다. 적용에 성공하면 "데이터를 적용했습니다"
   안내와 함께 "추천 실행" 버튼이 나타납니다.

### 현재 사용 중 데이터 vs 검사 중 데이터
- 지금 앱에 적용된 데이터는 **"현재 사용 중 데이터"** 카드(출처·파일/샘플명·시트·분석 사용 행·데이터 상태·
  추천 실행 상태)에, 방금 올려 검사만 된 데이터는 **"검사 중인 데이터"** 에 **따로** 표시됩니다. 올린 파일이
  곧바로 현재 데이터처럼 보이지 않습니다. 내부 경로·서명 같은 기술 값은 표시하지 않습니다.

### 적용 전에는 기존 데이터가 유지됩니다
- 새 파일이 **오류든 정상이든**, "이 데이터 사용"을 누르기 전까지 홈·추천 실행·검증은 **현재 적용 데이터**로
  계속 동작합니다. 새 파일이 사용 불가여도 전체 앱이 멈추지 않고, 홈에는 "검사 완료된 새 데이터가 있습니다"
  라는 짧은 안내만 표시됩니다.

### 적용 성공 시 이전 추천이 초기화됩니다
- 다른 데이터를 적용하면 이전 추천·후보·경로 상세·시뮬레이션·민감도/신뢰도 결과가 함께 초기화됩니다(원자적).
  **같은 데이터를 다시 적용**하면 불필요한 초기화 없이 그대로 유지됩니다.

### 적용에 실패하면 기존 데이터가 유지됩니다
- 적용 중 문제가 생기면 "새 데이터를 적용하지 못했습니다. 현재 사용 중인 데이터는 그대로 유지했습니다."
  안내만 보여주고, 기존 데이터·추천·검사 결과를 모두 보존합니다(내부 오류는 화면에 노출하지 않습니다).

### 같은 데이터 재업로드
- 파일명이 아니라 **내용**으로 판단합니다. 내용이 같으면 "현재 데이터와 동일"로 표시하고, 파일명이 같아도
  내용이 바뀌면 새 데이터로 검사합니다.

### 검사 취소 / 샘플 / 현재 데이터 초기화
- **검사 중인 데이터 취소**: 검사 결과만 지우고 현재 데이터는 유지합니다.
- **샘플 데이터 사용**: "① 기본 시뮬레이션 샘플" 또는 "② DQN 학습 샘플"에서 "선택한 샘플 적용"을 누르면
  버튼 클릭이 곧 적용입니다(샘플임이 분명히 표시되고 업로드 데이터와 섞이지 않습니다).
- **현재 데이터 초기화**: 앱에 적용된 데이터와 분석 결과만 비웁니다. 사용자의 원본 파일은 삭제하지 않으며,
  화면은 "데이터를 준비하세요"(데이터 없음)로 돌아갑니다.

## 2. 추천 실행

1. **데이터 관리** 페이지에서 "① 기본 시뮬레이션 샘플"로 샘플을 적용하거나, 상단 데이터 바로 파일을 올린 뒤
   검사 결과를 확인하고 "이 데이터 사용"(경고면 "문제 행을 제외하고 사용")을 눌러 적용합니다.
2. 데이터가 **적용되면** 분석 파이프라인이 돌아 추천이 만들어집니다(DQN은 실행되지 않습니다).
3. 검사 결과가 "사용 가능/확인 필요"면 적용할 수 있고, "사용 불가"면 안내에 따라 데이터를 고칩니다.

## 3. 결과 확인 (홈)

홈은 현재 상태에 따라 **하나의 상태와 다음 행동 하나**만 보여줍니다(`services/home_state.py`).

### 홈 상태별 의미와 눌러야 할 버튼
- **데이터를 준비하세요** — 아직 적용된 데이터가 없습니다. "데이터 불러오기"로 데이터 관리로 이동합니다.
- **검사한 데이터를 적용하세요** — 적용된 데이터는 없지만 검사만 끝난 파일이 있습니다. "데이터 적용"으로
  데이터 관리에서 "이 데이터 사용"을 누릅니다.
- **데이터를 수정해야 합니다** — 올린 파일에 오류가 있고 **적용된 정상 데이터가 없어** 사용할 수 없습니다
  (핵심 오류와 오류 건수 표시). "문제 확인"으로 데이터 관리에서 고칩니다. **이미 정상 데이터가 적용돼 있으면**
  이 상태로 넘어가지 않고 현재 결과를 유지한 채 "검사 완료된 새 데이터가 있습니다" 안내만 보여줍니다.
- **추천할 이동이 없습니다** — 데이터는 정상이지만 추천 가능한 이동이 없습니다. 홈이 주요 원인을 한두 문장으로
  요약합니다(예: "후보 18건 중 14건 — 출발 점포 재고보다 이동 수량이 많습니다."). "제외 이유 확인"으로
  추천 실행 페이지의 제외 후보 목록을 봅니다.
- **추천 결과가 있음** — 결과 KPI(추천 후보·권장 이동 수량·예상 순효과·추천 신뢰도·데이터 상태)와
  최우선 추천 카드, 이동 시뮬레이션, 추천 Top 5가 나타납니다.

### 최우선 추천 카드 읽는 방법
- 상품, 출발 → 도착, 이동 방식(직접/DC 경유·경유 DC명), 권장 이동 수량, 예상 순효과, 추천 신뢰도,
  가장 중요한 추천 이유 1개를 보여줍니다. "추천 상세 보기"를 누르면 그 후보의 경로 상세로 이동합니다.
- 내부 후보 ID·점수·서명 같은 기술 값은 홈에 표시하지 않습니다.

### KPI 표시 규칙
- 결과 KPI는 추천 결과가 있을 때만 나타납니다. 실행 전이나 계산 실패 상태에서 수치를 0으로 채우지
  않습니다(대신 상태 카드가 그 자리를 대신합니다).
- 이동 시뮬레이션: DIRECT는 실선, VIA_DC는 점선, DC01/DC02는 구분되어 표시됩니다.

### 데이터를 바꾸면 결과가 초기화되는 이유
- 새 데이터를 적용하면 이전 추천·선택·KPI가 즉시 사라집니다. 후보마다 데이터 서명이 붙어 있어
  다른 데이터의 옛 결과가 현재 결과로 잘못 표시되지 않습니다. 서명이 바뀌면 홈은 과거 KPI와
  최우선 추천을 숨기고 새 상태를 보여줍니다.

## 4. 추천 상세 (추천 실행 → 경로 상세)

- **추천 실행** 페이지: 상단에 추천 신뢰도와 실행 가능/데이터 확인 필요/이동 불가 건수를 요약합니다.
  기본 표에는 출발·도착·상품·수량·경로·예상 절감액·추천 등급·**실행 상태**가 보입니다.
- VHS/Greedy/DQN/Pareto 세부 비교값은 "상세 비교 보기"(접힘)에서 확인합니다.
- **경로 상세** 페이지: 선택한 추천 한 건의 이동 단계, 예상 비용·시간, 이동 전후 재고, 이동 방식 비교, 추천 이유를 봅니다.

### 추천 이유 읽는 방법
- "추천 판단 근거"에 **최대 3개**의 짧은 이유가 중요한 순서로 표시됩니다(예: 상위 VHS, 예상 절감액,
  Greedy 일치). 실제 계산값 기반이며 생성형 문장이 아닙니다.
- 그 아래 한 줄로 **왜 이 수량인지**를 봅니다. 예: "도착 점포 부족량을 기준으로 12개 이동을 권장합니다."
  이동 가능 수량이 예상보다 적다면 이 문장이 무엇이 수량을 제한했는지 알려줍니다.

### 추천되지 않은 후보 확인 방법
- 추천 실행 페이지 아래 **"추천에서 제외된 후보 N건"**(접힘)을 엽니다. 출발·도착·상품·상태·가장 중요한
  이유·원본 위치가 보입니다. 전체 내부 계산값은 표시하지 않습니다.
- 분석 및 검증 → **검증 결과** 탭의 "후보 판단 요약"에서 추천/확인 필요/이동 불가/데이터 부족/계산 불가
  건수와 주요 제외 이유를 한눈에 봅니다.
- 검토·수정을 위해 **제외 후보 검토 CSV**(UTF-8 BOM)를 내려받을 수 있습니다. Excel에서 한글이 깨지지 않습니다.

### 원본 데이터 위치 확인 방법
- 추천 판단 근거 아래 **"원본 데이터 확인 (관련 행 N개)"**(접힘)을 엽니다. 파일명·시트명·원본 행·컬럼·
  입력값·해당 값의 역할이 보입니다. 예: 재고현황 시트 12행 현재 재고 15 → 이동 가능 수량 계산에 사용.
- 여기 표시되는 행 번호는 **데이터 관리의 문제 목록과 같은 원본 위치**입니다. 표시가 "추적 불가"이면
  원본 파일에서 해당 관계를 찾지 못한 것이며, 임의의 행을 연결하지 않습니다.

### 데이터 수정 후 다시 분석하는 방법
1. 원본 위치에서 확인한 셀을 Excel/CSV에서 고칩니다(예: 잘못된 재고 값, 없는 경로 추가).
2. 데이터 관리에서 수정한 파일을 다시 업로드하거나 샘플을 다시 적용합니다.
3. 데이터가 바뀌면 이전 추천·선택·계보가 자동으로 초기화되고 새 결과가 계산됩니다.

## 5. 검증 화면 (분석 및 검증)

분석 및 검증 페이지는 **홈과 같은 현재 상태**를 사용합니다(`services/home_state.py`). 추천 결과가
있을 때만 6개 알고리즘 탭이 열리고, 그 외 상태에서는 상태 카드 하나와 다음 행동 하나만 보여줍니다.
분석 전이나 후보 0건에서 빈 탭·빈 차트·0으로 채운 검증 KPI를 늘어놓지 않습니다.

### 상태별 화면
- **데이터 없음** — "데이터를 준비하세요" + "데이터 불러오기". 검증 탭은 열리지 않습니다.
- **사용 불가 데이터** — "데이터를 수정해야 합니다"(핵심 오류) + "문제 확인". 이전 검증 결과는 숨겨집니다.
- **데이터 변경(서명 불일치)** — "데이터가 변경되었습니다" + 다시 적용 안내. 과거 민감도·신뢰도·DQN 결과를
  현재 결과처럼 보여주지 않습니다.
- **추천할 이동 없음** — "추천할 이동이 없습니다" + **후보 판단 요약**(아래) + "제외 이유 확인".
- **정상 결과** — 6개 탭이 열립니다.

### 후보가 0건일 때 확인 순서
1. **후보 판단 요약** 카드에서 전체 생성 후보와 상태별 수(추천·확인 필요·이동 불가·데이터 부족·계산 불가)를
   봅니다. 카드 합계는 전체 생성 후보 수와 일치합니다.
2. "주요 제외 이유"에서 가장 많은 원인 1~3개와 건수를 확인합니다
   (예: "출발 점포 재고보다 이동 수량이 많습니다 4건").
3. **추천에서 제외된 후보**(접힘)에서 출발·도착·상품·상태·핵심 이유·원본 위치를 확인하고, 필요하면
   **제외 후보 검토 CSV**(UTF-8 BOM)를 내려받습니다.
4. 원본 위치(시트·행)를 데이터 관리에서 열어 값을 고친 뒤 다시 적용합니다.

### 정상 결과일 때 탭 읽는 방법
- **추천 점수 / 점수 구성**: 현재 VHS와 구성 그룹.
- **비교 분석**: VHS(최종 추천) · Greedy(기준선) · Pareto(보조 검증). 상위 추천 일치 여부와 차이만 짧게
  보고, 알고리즘을 사용자가 고르지 않습니다.
- **민감도**: 추천 안정성(안정/검토 필요/불안정/계산 불가), 상위 추천 유지율, 순위 변동 후보, 가장 민감한 요소.
  이 값들은 **정상 결과가 있을 때만** 나타나며, 후보 0건에서 안정성 0%처럼 위장하지 않습니다.
- **DQN 학습**: 선택형 DQN 상태·학습 실행·결과·원본/균형형 비교. DQN 미실행은 전체 검증 실패가 아니며,
  DQN이 없어도 안정성·신뢰도는 표시됩니다.
- **검증 결과**: 후보 판단 요약 + 신뢰도·순위 안정성·비교 일치도 요약과 다운로드.

## 6. DQN 선택형 사용

- 분석 및 검증 → **DQN 학습** 탭에서만 사용합니다. 버튼을 누르기 전에는 학습되지 않습니다.
- "DQN 학습 실행"은 현재 적용 데이터로 학습합니다. `torch`가 없으면 "실행 환경 필요"로 표시됩니다.
- 결과가 "정상"이고 현재 데이터와 일치할 때만 낮은 비중으로 참고 반영되며, 최종 추천은 항상 VHS가 결정합니다.

## 7. 오류 해결

- 화면에는 traceback 대신 "무엇이 문제인지 / 어느 데이터인지 / 무엇을 고쳐야 하는지"가 표시됩니다.
- "검증 오류"가 있으면 추천이 적용되지 않습니다. 데이터 관리의 검증 메시지를 보고 해당 시트/컬럼을 수정하세요.
- 데이터를 바꾸면 이전 분석·이전 DQN 결과·선택 상태가 초기화되어 잘못 반영되지 않습니다.

## 8. 자주 발생하는 데이터 문제

- **필수 컬럼 누락**: `stores.node_type`, `inventory.stock_qty`, `routes.distance_km` 등이 없으면 오류.
- **잘못된 숫자**: 수량/비용/거리 컬럼의 문자열·음수·빈값 → 오류 또는 `-` 표시.
- **후보 0건**: 양의 절감액 후보가 없거나 모든 후보가 실행 불가능이면 추천이 비어 있을 수 있습니다.
- **존재하지 않는 점포/DC**: `routes`/`recommendations`의 ID가 `stores.node_id`에 없으면 오류.
- **DC 혼동**: DC01/DC02는 각각 `node_type=DC` 행으로 두어야 구분됩니다.
- **한글 파일명·공백**: 지원되지만, 컬럼명 앞뒤 공백은 자동 정리됩니다.
